Glossary

Every term used on this site, in plain language. Where a term has a particular meaning in the builder, a second line says what it is.

The primer introduces these ideas in order. This page is for looking one up.

A

Amplitude
One of the numbers that describe a set of qubits before they are measured. There is one amplitude for every bit string the qubits could return, and the squared size of an amplitude is the probability of measuring its bit string. An amplitude has a direction as well as a size; the direction is its phase.
Angles (gamma and beta)
The adjustable numbers in a QAOA circuit. Each layer has one gamma, which sets how strongly the phase separator marks assignments by cost, and one beta, which sets how far the mixer moves weight between assignments. A circuit with p layers has 2p angles.
In this tool: the circuit is built with its angles left open. The page then tries 200 random settings and refines the best of them.
Assignment
One complete set of answers: a 0 or a 1 for every variable. Written as a bit string, variable 0 first.
In this tool: x = [0 1 0 0 1 0] sets variables 1 and 4 to 1. For MaxCut an assignment is one way of splitting the nodes into two groups.

B

Backend
A machine that runs circuits, or a simulator standing in for one. In Qiskit a backend is an object that knows which gates its machine has and which of its qubits are connected.
In this tool: the script in a hardware package runs its circuit on the backend you choose.
Bit string
A sequence of 0s and 1s. Measuring n qubits returns a bit string of length n, which this tool reads as an assignment.

C

Certified optimum
The lowest cost any assignment can have, found by checking every assignment. It is certified because nothing was left unchecked.
In this tool: computed for problems of up to 24 variables. Every QAOA result is reported next to it.
Circuit
A list of gates applied to a set of qubits in order, ending in a measurement. The quantum counterpart of a program.
Command line
A way of running a program by typing its name and its options into a terminal, instead of clicking in a window.
In this tool: python -m qopt_builder does what the page does, from a terminal. See the command line.
Cost
The number a problem attaches to each assignment. The builder always minimises, so lower is better. For MaxCut the cost is minus the weight of the cut, which turns "cut as much as possible" into "make the cost as low as possible".
Coupling
A term of the cost that involves two variables: an amount added when both are 1. In a graph problem every edge gives one coupling. In the circuit every coupling becomes one RZZ gate per layer.
Coupling density
The share of variable pairs that have a coupling, from 0 (no pair interacts) to 1 (every pair does). For a graph it is the number of edges divided by the number of possible edges.
In this tool: the recommendation chooses the number of layers from it: 1 layer up to 0.15, 2 up to 0.5, and 3 above that.
Cut
In MaxCut, an edge is cut when its two ends are in different groups. The weight of a cut is the total weight of the edges it cuts.

D

Depth (of a circuit)
The number of time steps a circuit takes when gates on different qubits run side by side. A gate has to wait for every earlier gate that shares a qubit with it. Shallower circuits suffer less from noise on real hardware. This is a different number from p, the number of QAOA layers, which is sometimes also called depth.

E

Entanglement
A property of a state of several qubits that cannot be described one qubit at a time: the results of measuring them are linked. Two-qubit gates such as RZZ create it. A circuit with no two-qubit gates could be simulated one qubit at a time.
Exact solve
Finding the best assignment by computing the cost of every one. Simple and reliable, and possible only for small problems, because the number of assignments doubles with each variable.
In this tool: runs for up to 24 variables, in the Python package and in the browser.
Expected cost
The average cost you would get by measuring a circuit many times. It is how a QAOA circuit is scored: lower is better, and it cannot be lower than the optimum.
In this tool: computed exactly from the simulated amplitudes, not estimated from samples.

F

Free parameter
A number in a circuit that is left open for later and shown as a symbol. In a QAOA circuit the free parameters are the angles.
In this tool: the circuit card reports how many there are, normally two per layer.

G

Gap
The distance between the expected cost of a circuit and the certified optimum. A gap of 0 would mean every measurement returns a best answer.
Gate
One operation on one or two qubits. Each kind of gate changes amplitudes in a fixed way. This tool uses four: H, RZ, RZZ and RX.

H

H gate (Hadamard)
A one-qubit gate that takes a qubit that is definitely 0 to an equal superposition of 0 and 1. QAOA applies it to every qubit first, so that all assignments start out equally likely.
Hardware package
In this tool: a folder of five files that holds one problem, its circuit with the angles filled in, and a script that runs the circuit on a simulator or on a quantum computer and scores the results against the certified optimum. See running on hardware.
Heuristic
A method that often gives good answers but comes with no guarantee of how good. QAOA is a heuristic.

I

Interference
What happens when amplitudes are added together: those with the same phase reinforce, and those with opposite phase cancel. The mixer of a QAOA circuit uses it to move probability towards low-cost assignments.
Ising form
The same problem written with variables that are +1 or -1 instead of 0 or 1. It is the form in which a cost turns directly into gates: each term with one variable becomes an RZ gate, and each term with two becomes an RZZ gate.

J

Job
One request sent to a quantum computer: a circuit and a number of shots. A job waits in a queue, runs, and keeps an id by which its results can be fetched later.
In this tool: the script in a hardware package sends one job per run.

L

Layer
One phase separator followed by one mixer. A QAOA circuit is the H gates followed by p layers.

M

MaxCut
The problem of splitting the nodes of a weighted graph into two groups so that the total weight of the edges running between the groups is as large as possible.
Measurement
Reading the qubits. It returns one bit string, chosen at random with the probabilities set by the amplitudes, and it ends the computation.
Mixer
The part of a QAOA layer that moves weight between assignments: an RX gate on every qubit, all with the same angle beta.

N

Nelder-Mead
A standard classical method for improving a set of numbers without needing derivatives. It keeps a small cluster of trial settings and keeps replacing the worst one with a better one.
In this tool: the page uses it to refine the best angles found by the scan.
Noise
The errors of real quantum hardware: gates that are slightly off, qubits that lose their state, and measurements that misread. Noise grows with the depth of a circuit and with its number of two-qubit gates.
In this tool: the simulations on this site have none. A hardware package can rehearse a run on a simulated device that has it.

O

Offset
A constant added to every cost. It does not change which assignment is best, only the value reported.
In this tool: the vertex cover preset has an offset of 16.
OpenQASM
A plain text format for writing down a quantum circuit gate by gate, which most quantum software can read.
In this tool: a hardware package holds its circuit as an OpenQASM 2 file.
Optimum
The lowest cost any assignment has, and an assignment that has it. A problem can have several optimal assignments.
In this tool: when there are several, the builder reports the one with the lowest number, reading the assignment as a binary number with variable 0 as its lowest bit.

P

p (number of layers)
How many times a QAOA circuit repeats its phase separator and mixer. More layers can reach a lower expected cost, and make a longer circuit.
In this tool: chosen by the recommendation from the coupling density: 1, 2 or 3.
Phase
The direction of an amplitude, as opposed to its size. Phase does not affect a measurement made at once, but it decides how amplitudes combine in later gates.
Phase separator
The part of a QAOA layer that turns the phase of each assignment's amplitude in proportion to its cost: an RZZ gate for every coupling and an RZ gate for every term with one variable, all scaled by the angle gamma.

Q

QAOA
The quantum approximate optimisation algorithm: a way of building a circuit from an optimisation problem so that measuring it tends to return low-cost assignments. Introduced by Farhi, Goldstone and Gutmann in 2014.
Qiskit
IBM's open-source Python library for building, simulating and running quantum circuits.
In this tool: the Python package builds its circuits as Qiskit objects, and the script in a hardware package runs them through Qiskit.
Qubit
The basic unit of a quantum computer. Like a bit it gives 0 or 1 when read, but before that its state is described by amplitudes for both answers.
In this tool: one qubit per variable of the problem.
Qubit budget
The number of qubits available on the machine you intend to use.
In this tool: optional. If the problem has more variables than the budget, the builder refuses instead of shrinking the problem.
QUBO
Quadratic unconstrained binary optimisation: a problem whose cost is a sum of terms with one variable and terms with two, over variables that are 0 or 1. Written as a square table of numbers Q.
In this tool: the form every problem takes inside the builder. The table must be symmetric or triangular.

R

Refinement
Improving the angles step by step from a starting point, as opposed to trying unrelated settings.
In this tool: the page refines the best scanned angles with Nelder-Mead. The Python demo script scans only.
Refusal
The builder's answer when a problem needs more qubits than the stated budget: no circuit is built, and the reason is given.
RX gate
A one-qubit gate that moves weight between the answers 0 and 1 by a chosen angle. The mixer of a QAOA circuit is an RX gate on every qubit.
RZ gate
A one-qubit gate that turns the phase of the answer 1 relative to the answer 0 by a chosen angle, without changing either probability.
RZZ gate
A two-qubit gate that turns the phase one way when its two qubits agree and the other way when they differ. Each coupling of the problem becomes one RZZ gate in every layer.

S

Scan (angle scan)
Trying many unrelated settings of the angles and keeping the best.
In this tool: 200 random settings from a fixed seed, so the result is the same on every run. The page and the Python script draw their settings from different random generators, so their scan values differ.
Shot
One run of a circuit ending in one measurement, giving one bit string. Estimating probabilities on real hardware takes many shots.
In this tool: the script in a hardware package runs 1024 shots unless told otherwise.
Simulator
An ordinary program that computes what a quantum circuit would do, by keeping every amplitude in memory. Exact and free of noise, but its cost doubles with every qubit.
In this tool: the page simulates up to 14 qubits.
Statevector
The full list of amplitudes of a set of qubits: 2n numbers for n qubits.
Superposition
A state in which more than one answer has an amplitude that is not zero. A measurement still returns one answer.

T

Transpilation
Rewriting a circuit so that a particular machine can run it: using only the gates the machine has, and only between qubits that are connected on it. This usually adds gates and depth.
In this tool: the script in a hardware package has Qiskit do it before a circuit goes to a device, and reports the depth and the number of two-qubit gates of the result.

V

Variable
One yes-or-no decision of the problem, taking the value 0 or 1. Written x with a number, counted from 0.
Variational algorithm
A method that pairs a quantum circuit that has adjustable angles with a classical routine that tunes them, going back and forth between running the circuit and updating the angles.

W

Weight
The number on an edge of a graph. In MaxCut it is what a cut gains by separating the two ends of that edge.
